三、日常操作

1. 选工作簿与小班

打开工作簿 → 顶部按「项目类型 → 标段 → 乡 → 村 → 小班号」逐级选择或搜索 → 下方直接显示该小班的表单与流程。

只填网格数据时，点单元格直接改，自动保存（右上角显示"✓ 已保存"）。

2. 检查验收（流程）

  • 模板有多条流程时，顶部有流程下拉；前置流程未通过时显示 🔒，按顺序解锁。
  • 一条流程是一张整表单：所有环节一次填完，再选底部「✓ 通过 / ✗ 不通过」。
  • 必填项没填完时底部显示「还差 N 项」，点提交会列出缺项。
  • 不通过必须写原因（≥2 个汉字）；选「不通过」不受通过判断拦截。

3. 通过判断（模板规则）

数值 / 百分数 / 自动值控件下方会显示判断条：

  • 绿色 ✓ 正确：实测满足模板规则（如株数 ≥ 设计值、成活率 ≥ 85%）
  • 红色 ✗ 不正确：实测不满足；此时不能提交「通过」
  • 黄色 ? 无法判定：设计值缺失或实测不是数字
现场确实不达标时，选「不通过」并写明原因/整改要求，记录仍会留痕。

4. 环节内备注

某项选了模板标记为"需要说明"的选项（如「不正确」「未实施」），该环节就地展开备注框，必须写够模板要求的汉字数才能提交。切回正向选项后，备注框收起并清空，不会误提交旧文字。

5. 提交与日志

提交成功后，页面下方「提交日志」记录结论 / 操作人 / 时间 / 经纬度 / IP，新记录在前。主线流程通过后自动解锁下一步；巡护等独立流程随时可填，不影响主线。

6. 日常巡护（可多次）

  • 巡护是独立流程，可反复填报；每提交一次就是第 N 次记录。
  • 每次按模板填写巡视日期、巡视情况、问题等，并可上传监理通知、现场照片/PDF。

7. 材料检验（按批次）

苗木、肥料等材料检验不挂单个小班：在工作簿顶部点「🧱 材料检验」，按进场批次逐条登记。一条记录可关联多个小班，不阻塞各小班的造林工序。

8. 拍照 / 上传 / 打卡（流程附件）

按钮行为
📷 拍照调用相机，加水印（时间/坐标/备注）后存手机相册 Pictures/{目录}/，不上传原图
📎 上传选择图片或 PDF 上传到服务器（单文件 ≤10MB），随流程提交绑定
📍 打卡记录一次定位（经纬度/精度/时间），作为到场留痕

照片是否同步网盘由后台「云同步」决定；视频与照片原图都不在服务器长期保存。

9. 视频

点「🎬 视频」→ 系统相机录制 → 自动压缩并保存到手机相册同一目录，文件名带 _视频。视频只存手机本机，不上传网盘。

10. 卫星持续跟踪与轨迹

  • 授权定位后，通知栏常驻「卫星持续跟踪中」——让后续打卡/水印/拍照定位更快更准。
  • 记录轨迹仍要手动：点「◎ 轨迹」开始记录（通知栏显示"记录轨迹中 · 已录 N 点"），再点一次结束并上传。
  • 只记录 GPS 卫星点，不采集网络/WiFi 定位；轨迹按小班归属，切换小班会自动结算上一段。
  • 上传失败时点保留在手机，稍后再点「结束轨迹」重试。

11. 未提交草稿（不会因切小班丢）

  • 流程填到一半切到别的小班，内容会按「工作簿 + 小班 + 流程」分别保存在本机。
  • 回到原小班/原流程时自动恢复，顶部提示「未提交草稿（时间）」，可点「丢弃草稿」恢复为已提交内容。
  • 草稿保留 7 天，最多 30 份；提交成功后自动清除。

12. 导出

  • 详情页右上角「⬇ 导出」；后台「下载 Excel」同样按上传模板回填。
  • 导出文件包含：原数据 sheet（格式不变）+ 「流程填报」sheet（每个小班每条流程的实测值、备注、结论、操作人、时间、定位、附件清单、IP）。
  • 照片原图只在本机/网盘，不在 Excel 里；上传的 PDF/图片以文件名清单出现在附件列。

板块作用
模板管理上传 / 更新 / 下载 Excel；下架（软删除，可恢复）或彻底删除；显示流程模板版本、判断/备注配置数与配置告警

模板更新：流程、参数、判断规则、备注规则都是上传时的快照。拿到新模板后，在「模板管理」点「更新 Excel」就地合并（工作簿编号不变，已填数据保留）；旧工作簿不会自动获得新规则。

五、权限设置（重要）

轨迹、录像、卫星跟踪要在息屏后继续，必须让系统允许"后台运行"：

  1. 首次进入 App 时系统会弹「允许后台运行 / 忽略电池优化」→ 点 允许
  2. 华为机型额外设置：手机管家 → 应用启动管理 → 监督验收 → 改为手动管理，并把「自启动 / 关联启动 / 后台活动」三项全部打开
  3. 通知权限必须允许（前台服务靠通知常驻；通知栏出现「卫星持续跟踪中」= 正常）

六、常见问题

现象处理
数值填了但看不到"正确/不正确"当前工作簿是旧模板（没有判断规则）。请管理员在后台「更新 Excel」上传含 →规则 的新模板
选了错误项没有出现备注框模板没写 →备注≥N。请管理员更新模板或在模板控件里补规则
提交被拦"通过判断未通过"实测值不满足模板阈值。整改后重填；确实不达标请选「不通过」并写备注
切换小班后填的内容不见了先回到原小班/原流程，顶部会提示并恢复未提交草稿；超过 7 天或手动丢弃则不再恢复
上传附件失败检查网络与文件大小（≤10MB，仅图片/PDF）；弱网下先拍本地照片，回到有信号处再上传
息屏后轨迹没继续检查第五节"后台运行"设置与定位权限
轨迹点数很少纯 GPS，密林/室内冷启动可能 30 秒~几分钟不出点；到开阔处即恢复
拍的照片找不到相册 → Pictures/{目录}/
导出的 Excel 里没有照片原图照片按设计只存手机/网盘；Excel 里只有附件文件名清单
后台"填报进度"显示未填流程尚未「通过/不通过」提交；只填了网格单元格不算流程提交
忘记密码找管理员重置
