监督验收 App 使用说明

适用范围：中幼林抚育验收（网格填表 + 拍照 / 录像 / 轨迹留证）　·　版本 App v0.20 / 服务端 v0.20　·　更新 2026-09-14

一、安装

下载地址：https://www.pgyer.com/hqz-sp08

  • 打开页面点「安装」；若提示"未知来源 / 风险提示"，选择继续安装即可
  • 备用直链（始终指向最新版）：https://forest.bibook.top/supervision/apk
  • 首次进入 App 请全部允许：相机、麦克风、定位、通知；系统问"是否允许后台运行"时选 允许

二、登录

姓名（登录用户名）权限
尹学章 / 杨磊 / 何明星 / 赵强填写验收数据
苏正鹏 / 雷华雄填写数据 + 后台管理
规则：用户名 = 本人汉字姓名；密码 = 姓名小写首字母 + 123（例：尹学章 → yxz123；苏正鹏 → szp123）。登录状态本机长期保存（10 年），不必每次登录；换手机/重装后重新登录一次。
修改密码：点右上角自己的姓名 → 输入原密码 + 新密码 → 保存（只能改自己的，不影响其他同事；忘记密码找管理员重置）。

三、日常操作

1. 选小班

打开工作簿 → 顶部搜索框输入或点选小班号 → 进入该小班填写页。

2. 填表

点单元格直接修改，自动保存（右上角显示"✓ 已保存"）。

3. 验收结果（自动填验收人 / 时间）

点一下「验收结果」单元格 → 弹出选项 → 选 合格 或 不合格：

  • 自动填写 验收人 = 当前登录人、验收日期 = 今天
  • 选空白（视为未验收）→ 验收人 / 验收日期 / 验收备注一并清空

4. 拍照（📷 拍照）

  • 自动加时间水印（时间 / 坐标 / 备注）后存到手机相册：Pictures/{目录}/
  • 是否上传网盘由后台设置决定，当前默认开启——照片经服务器中转同步到网盘（目录结构与手机相册一致）
  • App 内「拍摄记录」只显示文件名与位置，不预览大图（避免卡顿）

5. 录像（🎬 视频）

  • 点按钮 → 调系统相机录像 → 录完确认 → 自动压缩并保存到相册同一目录，文件名带 _视频
  • 视频只存手机本机，不上传网盘
  • 录完会提示压缩效果，例如 （已压缩 46.1MB → 8.2MB）

6. 轨迹（◎ 轨迹）

  • 点一下开始记录（通知栏出现「轨迹记录中」），再点一次停止并上传
  • 只记录 GPS 卫星定位（不采集网络 / WiFi 定位），坐标与 ArcGIS 底图一致
  • 记录中若切换小班 / 开始录像 / 返回列表，会自动停止并保存上一段轨迹
  • 上传后管理员可在后台「轨迹下载」按小班分文件夹下载（含 shapefile，ArcGIS 直接打开）
轨迹要在息屏后继续记录，必须允许"后台运行"权限——详见第五节。

7. 导出

详情页右上角「⬇ 导出」→ 按上传的原始模板导出 Excel（格式与模板完全一致）。

四、后台设置（仅管理员：苏正鹏 / 雷华雄）

后台地址：https://forest.bibook.top/supervision/admin（三块设置互相独立）

板块作用
图片压缩（手机端）照片压缩的长边与质量；工作簿参数表里没配时用这里的默认值
视频压缩（手机端录制 + 原生转码）相机录制质量、转码分辨率 / 码率、单段最长时长等
云同步（照片 → 七牛 → 百度网盘）只决定照片是否上传网盘，与压缩无关
用户管理管理员为他人重置密码（无需原密码）；被重置者需用新密码重新登录，其他人不受影响

当前默认值

  • 照片：最长边 1440px、质量 0.8 → 通常压到原图的 1/10 ~ 1/25（多数手机照片约 1/20）
  • 视频：1080p / 4000kbps → 约为相机原片的 1/3 ~ 1/5；想更省流量可改 720p / 1500kbps（约 1/10）
  • 云同步：开启（照片上云；视频不上云）

五、权限设置（重要）

轨迹 / 录像要在息屏后继续，必须让系统允许"后台运行"：

  1. 首次进入 App 时系统会弹「允许后台运行 / 忽略电池优化」→ 点 允许
  2. 华为机型额外设置：手机管家 → 应用启动管理 → 监督验收 → 改为手动管理，并把「自启动 / 关联启动 / 后台活动」三项全部打开
  3. 通知权限必须允许（前台服务靠通知常驻；通知栏出现「轨迹记录中」= 正常运行中）

六、常见问题

现象处理
息屏后轨迹没继续记录检查第五节"后台运行"设置；确认定位权限已允许
轨迹没有点 / 点数很少纯 GPS 记录，密林或室内冷启动可能 30 秒~几分钟不出点；走到开阔处即恢复（宁可空白也不记偏点）
拍的照片找不到相册 → Pictures/{目录}/
录像后回到列表 / 文件名没记上请安装最新版 App（v0.17 起已修复）
又要求登录登录状态本机长期保存；若要求登录，重新输入一次即可
忘记密码找管理员在后台「用户管理」里重置

七、技术支持

遇到问题请把操作步骤 + 屏幕提示文字（最好附截图）发给管理员，便于快速定位。
