# 039 - v0.47 迭代记录_单流程与无类型路由

## 1. 需求背景（用户原话）

> 后续是否添加 excel，就能够解析不修改代码，兼容有多个流程或只有一个流程的验收，
> 比如没有项目类型的，就默认走全部路由？可以修改模板来适配程序，最小改动程序实现

口径：**模板适配程序**（固定 sheet 名与表头），程序只补一处缺口——数据表没有
「项目类型」列时，不要把所有流程都判成"未命中"。

## 2. 验证结果（改前数据对比/报错现场）

用两个最小工作簿直接跑 `flow_tpl.parse` + `flow_hit._tpl_hit`（不落库）：

- 单流程、路由「项目类型」留空、数据表无该列 → **命中 1 条**，3 个环节正常返回（现状已可用）；
- 单流程、路由写「人工造林」、数据表无该列 → **命中 0 条**（`_tpl_hit` 返回 None），
  界面打不开任何流程。这正是需要补的"默认走全部路由"。

## 3. 设计方案（逻辑+口径依据，引用证据文件）

1. **无列 = 不按类型过滤**：`_tpl_row_type` 在表头找不到「项目类型」时返回 `None`；
   `routes_for(flows, None)` 返回全部路由。**有列但值为空仍按空类型严格匹配**，
   避免多类型工作簿里一条脏数据突然看到所有流程。
2. **路由顺序不变**：回退后仍按「主线序号在前、独立流程最后」排序，默认流程规则（C28⑤）照旧。
3. **单流程界面收敛**：`flow_list` 只有一条时不渲染流程下拉；`cond_val` 为空时
   标题不再显示「项目类型：」（触发方式/独立/可重复提示保留）。
4. **模板约定不变**：仍然是 `设计值` + `流程路由`（固定 7 列，项目类型可空）+ `流程-*`
   （固定 6 列）。单流程模板 = 路由 1 行 + 1 张流程表，不需要改代码。

## 4. 代码修改（文件+行号+要点，不写全 diff）

- `flow_hit.py::_tpl_row_type`：表头无「项目类型」→ 返回 `None`；有列照旧返回值。
- `flow_tpl.py::routes_for`：`project_type is None` → 全部路由；其余仍等值过滤。
- `flow_hit.py::_tpl_hit`：payload 的 `cond_val` 用 `ptype or ''`（前端不出现 None）。
- `static/flow.js::renderV2`：标题 meta 改为按需拼装；`list.length > 1` 才渲染流程下拉，
  没有提示内容时连 `.flow-pick` 容器都不输出。
- `tests/test_unit.py`：新增 K1–K4（单流程命中 / 无列回退 / 有列不匹配仍拒绝 / 多流程排序）。
- `templates/index.html`：静态资源 `?v=0.45.0 → 0.47.0`。

## 6. 反转记录（反转了哪条旧决策，为什么；无则写「无」）

- 反转「v2 路由必须按项目类型严格匹配才能命中」：单流程/全量验收模板没有项目类型维度，
