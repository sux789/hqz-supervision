# 014-后台隐藏轨迹卡片（v0.27）

> 版本：v0.27 ｜ 日期：2026-09-17 ｜ 状态：已实现并本地实测通过
> 关联约束：**C16（新增）**、C08、C13

## 一、需求

用户要求：`后台隐藏 .gpx 的 <table class="tbl" id="tblTrack">`。

## 二、做法与理由

`tblTrack` 是后台「轨迹下载」卡片里的 GPX 文件列表。**整张卡片一起注释掉**（标题 + 说明 +
「下载全部轨迹 zip」按钮 + 表格），而不是只藏表格：

- 只藏表格会留下 `前端（B3）产生的 GPX 轨迹将出现在这里。` 的空文案 + 一个没有列表的打包下载按钮，
  比整块隐藏更难看、更让人困惑；
- 与 v0.22 隐藏「云同步 / 用户管理」两张卡片的做法一致：**后端接口与数据全部保留，删掉注释即可整块恢复**。

保留不动的后端：`GET /admin/api/tracks`、`GET /admin/api/tracks.zip`、`GET /admin/api/tracks/<name>`，
以及磁盘上的 `data/tracks/`。

## 三、顺带修掉一个会让整个后台失效的地雷（本次最重要的部分）

`static/admin.js` 里有一行**顶层语句**：

```js
$('#btnZip').addEventListener('click', () => { location.href = ... });
```

它没有空元素保护。卡片一旦被注释掉，`$('#btnZip')` 返回 `null` →
`null.addEventListener` 抛 TypeError → **整个 `admin.js` 加载失败**，
后果是后台**整页失效**（模板列表、上传、下载、下架按钮全部没反应）。

这正是 v0.22 引入 `on()` 辅助函数要解决的场景，但当时只覆盖了被注释掉的那两张卡片的元素，
`#btnZip` 漏掉了（v0.26 我加「更新 Excel」/筛选按钮时也没动它）。

修复：

```js
// static/admin.js
on('#btnZip', 'click', () => { ... });        // 元素缺失就跳过

async function loadTracks() {
  const tb = $('#tblTrack tbody');
  if (!tb) return;                             // 卡片被注释掉时静默跳过，别报错
  ...
}
```

## 五、恢复方法

`templates/admin.html` 里搜索 `v0.27`，删掉包住该 `<section class="card">` 的
`<!--` 与 `-->` 即可整块恢复，**无需改 JS**（`#btnZip` 已用 `on()` 包装）。
