# 040 - v0.48 迭代记录_导出明细、填报进度与草稿隔离

> 版本：v0.48 ｜ 业务口径：无变化 ｜ 日期：2026-10-28 ｜ 前置：doc/039（v0.47）

## 1. 需求背景（用户原话）

> 自行整理出性价比高的优化列表，从客户角度整理出要修改的问题列表，确认后再执行优化

从客户视角梳理后确认本轮做三项 P0 + 文档/提示：

1. **导出 Excel 缺流程填报内容**：客户拿到文件只有设计值，内业归档/迎检没有实测、备注、结论、附件；
2. **后台看不到填报进度与内容**：管理层无法线上核实哪个小班填了、谁填的；
3. **切换小班会清掉未提交草稿**：v2 整条提交，未提交=未落库，填一半换小班就丢；
4. 顺带：使用说明与 App 内指南仍停在 v0.20；旧工作簿静默不生效没有提示。

另确认：先把 v0.44–v0.47 收口发布，再叠加本版。

## 2. 验证结果（改前数据对比/报错现场）

- **导出**：`main.py::_export_workbook` 只回填数据 sheet 的 `rows`；v2 流程值存 `flow_records`，
  文件里完全没有。本地用 wid=864 导出，sheet 只有 `设计值/流程路由/流程-* /说明/参数`，无任何填报值。
- **进度**：`templates/admin.html` 只有模板管理、压缩、云同步、验收变更日志、运行日志；
  没有任何按小班/流程的填报状态接口或卡片。
- **草稿**：`static/flow.js` 只有一个 `hqz_sup_flow_draft_v1`；`open()` 在 `wid/row/flow` 不同时
  直接 `clearDraft()`。现场填一半切小班，上一份草稿被删除；12 小时过期。
- **线上现状**：部署前线上仍是 v0.43；模板宽表已上传但流程快照是旧版（无判断/备注规则）。
  浏览器实测后台列表可看到「未配置判断/备注」提示。

## 3. 设计方案（逻辑+口径依据）

1. **导出追加「流程填报」长表**：数据 sheet 原样不动（C08）；
   一行 = 某小班某流程第 N 次的某个填报项；列含小班号/流程/第几次/环节/检查项/填报值/
   结论/操作人/提交时间/定位/附件清单/IP。筛选导出时只带被筛中的小班（复用同一份筛选判定）。
2. **后台填报进度只读**：`flow_records` + `flow_audit` 聚合出「小班 × 流程」矩阵
   （通过/不通过/未填、可重复流程次数、最近操作人/时间/定位）；点单元格出明细与提交日志。
   不新增写接口，不做权限外的操作。
3. **草稿隔离**：键改为 `工作簿|小班|流程`，多份保存；7 天过期、最多 30 份、空表单不落盘；
   恢复时顶部提示并可「丢弃草稿」；提交成功只清当前键。老单键草稿匹配时自动迁移。
4. **旧模板提示**：后台模板列表显示「流程模板 v2 · 判断 N · 备注 N」或缺省告警；
   App 工作簿列表给无判断/备注规则的 v2 模板打「旧模板」标记。

## 6. 反转记录（反转了哪条旧决策，为什么）

- **反转「导出只回填数据 sheet」**：数据 sheet 保留原样（C08 不反转），但增加「流程填报」长表——
  否则 v2 的实测/备注/结论/附件永远出不了系统，客户无法归档。
- **反转「流程只有一个全局草稿」**：v2 整条提交，切换小班时清空唯一草稿 = 直接丢现场数据；
  改为按小班/流程多份保存，仍遵守 C14「离场必冲刷」。
- 未反转：照片不落服务器（C07）、导出按原模板（C08）、后台只读边界（C13）。
