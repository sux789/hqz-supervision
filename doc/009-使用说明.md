## 三、日常操作

### 1. 选小班
打开工作簿 → 顶部搜索框输入或点选**小班号** → 进入该小班的填写页。

### 2. 填表
点单元格即可修改，**自动保存**（右上角显示"✓ 已保存"）。

### 3. 验收结果（自动填验收人/时间）
**点一下"验收结果"单元格** → 弹出选项 → 选 **合格** 或 **不合格**：

- 自动填写 **验收人 = 当前登录人**、**验收日期 = 今天**
- 若选**空白**（视为未验收）→ 验收人 / 验收日期 / 验收备注 **一并清空**

### 4. 拍照（📷 拍照）
- 照片**自动加时间水印**（时间 / 坐标 / 备注）后保存到手机相册：`Pictures/{目录}/`
- **是否上传网盘由后台设置决定**：当前默认**开启**——照片经服务器中转同步到网盘（与手机相册同一个目录结构）
- App 内「拍摄记录」只显示**文件名与位置**，不预览大图（避免卡顿）

### 5. 录像（🎬 视频）
- 点按钮 → 调**系统相机**录像 → 录完确认 → **自动压缩**并保存到手机相册同一目录，文件名带 `_视频`
- **视频只存手机本机，不上传网盘**
- 录完会提示压缩效果，例如：`（已压缩 46.1MB → 8.2MB）`

### 6. 轨迹（◎ 轨迹）
- 点一下开始记录（通知栏会出现「轨迹记录中」），再点一次**停止并上传**
- **只记录 GPS 卫星定位**（不采集网络/WiFi 定位），坐标与 ArcGIS 底图一致
- ⚠️ **轨迹要在息屏后继续记录，必须允许"后台运行"权限**（见第五节）
- 记录中若**切换小班 / 开始录像 / 返回列表**，会自动停止并保存上一段轨迹
- 走完上传后，管理员可在后台「轨迹下载」按小班分文件夹下载（含 shapefile，ArcGIS 可直接打开）

### 7. 导出
详情页右上角「⬇ 导出」→ 按上传的原始模板导出 Excel（格式与模板完全一致）。

## 四、后台设置（仅管理员：苏正鹏 / 雷华雄）

后台地址：<https://forest.bibook.top/supervision/admin>

后台分三块，**互相独立**：

| 板块 | 作用 |
|---|---|
| **图片压缩（手机端）** | 照片压缩的长边与质量。工作簿参数表里没配时用这里的默认值 |
| **视频压缩（手机端录制 + 原生转码）** | 相机录制质量、转码分辨率/码率、单段最长时长等 |
| **云同步（照片 → 七牛 → 百度网盘）** | 只决定**照片是否上传网盘**，与压缩无关 |

**当前默认值**：

- 照片：最长边 **1440px**、质量 **0.8** → 通常压到原图的 **1/10 ~ 1/25**（多数手机照片约 1/20），验收留证清晰够用
- 视频：**1080p / 4000kbps** → 约为相机原片的 **1/3 ~ 1/5**；想更省流量可改 720p / 1500kbps（约 1/10）
- 云同步：**开启**（照片会上云；视频不上云）
- 轨迹保留：七牛副本保留 30 天后自动清理（百度网盘长期保留）

## 五、权限设置（重要）

**轨迹/录像要在息屏后继续，必须让系统允许"后台运行"**：

1. 首次进入 App 时，系统会弹「允许后台运行 / 忽略电池优化」→ 点**允许**
2. 华为机型额外设置：**手机管家 → 应用启动管理 → 监督验收** → 改为**手动管理**，并把「自启动 / 关联启动 / 后台活动」**三项全部打开**
3. 通知权限必须允许（前台服务靠通知常驻，通知栏出现「轨迹记录中」= 正常运行中）

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 息屏后轨迹没继续记录 | 检查第五节"后台运行"设置；确认定位权限已允许 |
| 轨迹没有点 / 点数很少 | 纯 GPS 记录，密林或室内冷启动可能 30 秒~几分钟不出点；走到开阔处即恢复（宁可空白也不记偏点） |
| 拍的照片找不到 | 相册 → `Pictures/{目录}/`（与网盘目录结构一致） |
| 录像后回到列表 / 文件名没记上 | 请安装**最新版 App**（v0.17 起已修复） |
| 又要求登录 | 令牌有效期 180 天；重登一次即可 |
