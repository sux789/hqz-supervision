# 033 - v0.41 迭代记录_模板照片参数

> 模板：`data/tpl-人工造林-验收流程模板.xlsx`（参数页 5 → 10 键）
> 版本：v0.41 ｜ 日期：2026-10-27 ｜ 前置：doc/032（v0.40 提交日志）

## 1. 需求背景（用户原话）

> 帮我在模板中配置参数，比如图片本地保存目录，图片水印，图片压缩，信息参数

落地为：把程序已支持、但 v2 模板「参数」页没有的照片类配置补进模板，并让
`tpl_tool.py params` 以后能自动补齐这些 key。

## 2. 验证结果（改前数据对比/报错现场）

- v2 模板「参数」页只有 5 键：可编辑列 / 功能 / 搜索选项 / unique-key / 导出筛选；
- `PARAM_SPECS` 也只有这 5 键。手工往模板加照片参数后再跑 `params`，会被整页重写抹掉；
- 前端已消费但模板未声明的 key：`目录`（相册 Pictures/ 子目录）、`相片备注`（水印正文）、
  `相片文件名`、`压缩最长边`、`压缩质量`（static/app.js L1175-1189、L898-906）；
- 不配置时：目录为空 → 相册落 `Pictures/验收照片`；水印只有时间/坐标；压缩回落后台默认 1440/0.8。

## 3. 设计方案（逻辑+口径依据）

| key | 值（本次默认） | 程序行为 |
|---|---|---|
| `目录` | `{{项目类型}}/{{标段}}/{{小班号}}` | 本机相册 `Pictures/{目录}/`，按项目类型→标段→小班分层（C07 照片不落服务器） |
| `相片备注` | `{{项目类型}}{{标段}}{{乡（镇）}}{{村（社区）}}{{小班号}}小班` | 水印正文；首行时间戳固定不参数化（C06） |
| `相片文件名` | `{{标段}}_{{小班号}}_{{时间}}` | 文件名不含扩展名；`{{时间}}`=YYYYMMDD_HHMMSS |
| `压缩最长边` | `1440` | 新拍照片最长边 px；优先级：本表 → 后台图片压缩 → 内置兜底（C10） |
| `压缩质量` | `0.8` | JPEG 质量；建议 0.75-0.82，过低水印会出彩边 |

口径：

- **默认值从数据表头推导**：`_ph()` 只拼当前表里存在的列，不写死「项目名称」等不存在的字段；
- **`功能` 仍留空**：v2 的拍照入口在流程「附件」列里定义，打开 `拍照` 会额外显示旧的详情页按钮，
  本轮不改变界面功能开关；
- **“信息参数”**：按照片信息理解 = 水印正文 + 文件名 + 目录 + 压缩；EXIF（GPS/拍摄时间）保留与
  水印取值是程序固定行为（C20），不放进参数页；
- **同步语义**：`params` 只补缺失 key、已有值不覆盖；`--force` 才重置（C29①）。

## 6. 反转记录（反转了哪条旧决策，为什么）

1. **反转「照片参数只属于旧模板」**：v0.38 起 v2 模板成为主模板，但 `PARAM_SPECS` 仍只有 5 键，
   照片配置只能手写、且会被 `params` 抹掉。现在照片 key 成为模板一等配置。
2. **反转「目录/水印默认写死项目名」**：默认值改为从表头拼占位符，换项目类型/表头即可复用，
   不在工具里硬编码「人工造林」。
