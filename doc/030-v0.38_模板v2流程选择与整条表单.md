## 3. 设计方案（逻辑+口径依据）

| 决策 | 口径与依据 |
|---|---|
| schema 识别 | 同时存在 `设计值` + `流程路由` 即 v2（`flow_tpl.is_tpl_doc`），优先于其它两套；`workbooks.flows.schema='flow_tpl/1'` |
| 数据表 | v2 直接取 `设计值`（`_pick_data_sheet` 提前返回），不再要求「有且仅一个非参数 sheet」 |
| 参数 | v2 无「参数」sheet → 走 `_tpl_default_config`：搜索列 `小班号|search`，下拉筛选 `项目类型/标段/乡（镇）/村（社区）|select`；不手工造可编辑列 |
| 路由 | `流程路由` 一行一条：序号=界面顺序，前置流程=全部完成后才可发起，可重复=是 → 每次提交新增 `rec_no`。**结论看每条流程唯一的「是否通过」环节**（不能让每个环节都要求结论，否则永远 done=False） |
| 默认选中 | 按路由顺序取「前置全完成 + 自己未完成」的第一条；可重复流程永远可选；全做完落到最后一条，下拉不空 |
| 整条提交 | 模板的「备注」是**整条流程共用的一行**（隐藏，结论=不通过或任一 `→备注` 选项时展开）。分环节提交会出现"后面没填、前面已写库"的半成品 → v2 统一 `POST /flow/batch`，一次事务写完整条流程（各环节同一 `rec_no`） |
| 设计值 | `设计值表头` 三态：命中 data 列 → 按当前小班取值；`常量：xxx` → 固定值；留空 → 不显示。展示位置=控件输入框上方，`.fs-design` 放大（20px） |
| 自动公式 | 模板 `自动(公式)` 只走 AST 白名单（`+ - * /`、括号、一元），**不 eval 模板文本**；变量按 精确→后缀→包含 解析（公式写短名 `成活株数`、环节叫 `样地调查成活株数`），末尾 `%` 是展示单位；跨环节取值 → 求值前把**整条流程**的值铺平 |
| 服务端权威 | 必填/数值规则/备注 ≥2 汉字/流程路由闸门全部在 `/flow/batch` 复核（C13）；前端只做即时提示 |
| 老接口 | v2 工作簿走 `POST /flow` 直接 400，避免绕过整条校验写半截 |

## 6. 反转记录（反转了哪条旧决策，为什么）

1. **环节向导（v0.31 doc/019）→ 整条流程一次提交**：v2 模板的「备注」是整条流程共用的一行，按环节提交会造成半成品状态与循环依赖（前面环节要等后面备注），且一次流程只有一个结论按钮。
2. **「无参数 sheet 即拒绝上传」（C11 ①）→ v2 豁免**：v2 用 `设计值` 承担数据表 + 自带路由，参数能力由 `_tpl_default_config` 兜底；老格式的校验原样保留。
3. **网格兜底 → v2 不给网格**：用户明确要求去掉 `jexcel_container` 及旧提交区；v2 的填报入口就是流程表单，网格只作为打开失败时的最后兜底，不再默认出现。
4. **公式只看本环节 → 铺平整条流程**：`样地调查成活率` 的变量在第 13/14 行、公式在第 15 行；最初前后端都只传本环节值，导致自动字段恒为「—」（本轮真 bug，已由 e2e T8 守住）。
