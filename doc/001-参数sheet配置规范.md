> 版本：v0.1 ｜ 日期：2026-09-11 ｜ 状态：已定稿并落盘到 `data/中幼林抚育-网格填表模板.xlsx`「参数」sheet

## 一、需求

「参数」sheet 是网格填表功能的唯一配置源。原版（7 行无表头键值表）存在：分隔符混乱（`;`、`|`、全角`｜`混用）、`搜索选项` 笔误（`小班号;select`）、无类型/默认值/说明元信息、空值语义靠隐含约定。本版全面规范化。

## 三、设计

### 表结构（固定 6 列）

| 列 | 含义 |
|---|---|
| key | 配置键名，全表唯一 |
| value | 配置值（解析器实际消费的字段） |
| 类型 | 模板 / 列表 / 控件映射 / 布尔…（元信息，供人与校验器用） |
| 默认值 | value 缺失或留空时的取值；「—」表示必填无默认 |
| 说明 | 语义 + 语法说明 |
| 示例 | 展示渲染效果 |

### 分隔符语法（C02 约束）

| 符号 | 用途 | 示例 |
|---|---|---|
| `;`（半角） | 项与项分隔（列表类值） | `合格;不合格` |
| `\|`（半角） | 项内子字段分隔 | `小班号\|search` |
| `/` | 目录层级分隔 | `{{sheet名称}}/{{小班号}}` |
| `_` | 文件名段连接 | `{{分类}}_{{乡镇}}_{{村}}` |
| `{{…}}` | 占位符 | `{{列名}}`、`{{sheet名称}}`、`{{时间}}` |

- 占位符 `{{列名}}` 与数据 sheet 表头**严格匹配**，匹配失败报错不静默。
- 禁止全角标点（`｜`、`；`、`（`）出现在 value 中；解析器校验并报错带行号。

### 现有 10 键定义

| key | value | 类型 | 程序行为 |
|---|---|---|---|
| 相片备注 | `{{项目名称}}{{标段}}小班{{小班号}}` | 模板 | 拍照水印备注文字 |
| 相片文件名 | `{{标段}}_{{乡镇}}_{{村}}_{{小班号}}_{{时间}}` | 模板 | 照片文件名（不含扩展名）；`{{时间}}`=YYYYMMDD_HHMMSS。占位符必须是数据 sheet 真实表头（v0.3 修正：原 `{{分类}}` 非表头列，改为 `{{标段}}` 前缀） |
| 目录 | `{{sheet名称}}/{{小班号}}` | 模板 | 照片子目录；段内可混排文本与占位符（如 `{{小班号}}号调查小班`） |
| 验收结果选项 | `合格;不合格` | 列表 | 「验收结果」列下拉选项 |
| 可编辑列 | `验收人;验收日期;验收结果;验收备注` | 列表 | 允许编辑的列 |
| 不显示列 | （空） | 列表 | 隐藏列；空=全部显示 |
| 功能 | `拍照;轨迹` | 列表 | 功能开关，可选：拍照、轨迹、打卡 |
| 搜索选项 | `项目名称\|select;标段\|select;小班号\|search` | 控件映射 | 项=`字段\|控件类型`；`select`=下拉（适合选项少的字段）；`search`=前端本地搜索选中（输入即时过滤已加载的行，**不发服务端请求**，适合选项过多的字段如小班号）；字段须与表头一致 |
| 压缩最长边 | `1440` | 数值 | 手机端压缩最长边(px)，300-8000，**仅影响新拍照片**；缺省 1440（v0.9.3 方案 A） |
| 压缩质量 | `0.8` | 数值 | JPEG 质量 0.1-1，**仅影响新拍照片**；缺省 0.8。建议 0.75-0.82——再低水印文字会出现彩边 |

### 搜索控件实现口径（决策）

`search` 控件**定义为前端本地搜索**：对网格页已全量加载的数据行做防抖文本过滤 + 多词 AND 匹配（沿用 hqz-survey 演进结论——其原服务端 `api/subcompartments/search` 已被删除，理由：数据本就全量在前端，服务端请求徒增往返且山区弱网/离线不可用）。选型规则：选项 ≤ 50 个用 `select`，超过用 `search`。控件类型是封闭词表（C02），将来确有十万行级需求再扩展 `字段|search|remote` 修饰位，当前不预设。

### 水印版式（省比特版式，v0.9.3）

水印文字=「相片备注」模板渲染 + 固定日期行（C06）+ 可选坐标行，绘制为**半透明白底块 + 实心黑字**（alpha 0.62，圆角），贴画面左下角。
换版式的原因：旧版「白描边黑字」的描边是高频边缘，JPEG 要为它花大量比特；底块在同等质量下体积更小（实测同一底图 0.80 编码省约 7%），文字也更清晰（无彩边/马赛克）。
