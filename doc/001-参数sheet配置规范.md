## 三、设计

### 表结构（固定 6 列）

| 列 | 含义 |
|---|---|
| key | 配置键名，全表唯一 |
| value | 配置值（解析器实际消费的字段） |
| 类型 | 模板 / 列表 / 控件映射 / 布尔…（元信息，供人与校验器用） |
| 默认值 | value 缺失或留空时的取值；「—」表示必填无默认 |
| 说明 | 语义 + 语法说明 |
| 示例 | 展示渲染效果 |

### 分隔符语法（C02 约束）

| 符号 | 用途 | 示例 |
|---|---|---|
| `;`（半角） | 项与项分隔（列表类值） | `合格;不合格` |
| `\|`（半角） | 项内子字段分隔 | `小班号\|search` |
| `/` | 目录层级分隔 | `{{sheet名称}}/{{小班号}}` |
| `_` | 文件名段连接 | `{{分类}}_{{乡镇}}_{{村}}` |
| `{{…}}` | 占位符 | `{{列名}}`、`{{sheet名称}}`、`{{时间}}` |

- 占位符 `{{列名}}` 与数据 sheet 表头**严格匹配**，匹配失败报错不静默。
- 禁止全角标点（`｜`、`；`、`（`）出现在 value 中；解析器校验并报错带行号。

### 搜索控件实现口径（决策）

`search` 控件**定义为前端本地搜索**：对网格页已全量加载的数据行做防抖文本过滤 + 多词 AND 匹配（沿用 hqz-survey 演进结论——其原服务端 `api/subcompartments/search` 已被删除，理由：数据本就全量在前端，服务端请求徒增往返且山区弱网/离线不可用）。选型规则：选项 ≤ 50 个用 `select`，超过用 `search`。控件类型是封闭词表（C02），将来确有十万行级需求再扩展 `字段|search|remote` 修饰位，当前不预设。

### 水印版式（省比特版式，v0.9.3）

水印正文=「相片备注」模板渲染，首行=固定时间戳 `yyyy-MM-dd HH:mm:ss`（秒级，本地时区，C06 不参数化），可选坐标行，绘制为**半透明白底块 + 实心黑字**（alpha 0.62，圆角），贴画面左下角。
换版式的原因：旧版「白描边黑字」的描边是高频边缘，JPEG 要为它花大量比特；底块在同等质量下体积更小（实测同一底图 0.80 编码省约 7%），文字也更清晰（无彩边/马赛克）。

排版参数（v0.9.5）：备注每行 26 字自动换行；底块内边距 = 字号×0.7（横向）/×0.5（纵向），行距 ×1.45，圆角 ×0.35，外边距 ×0.55；底块最小宽度 = 画面宽 30%（短备注不显得局促）；**若换行后底块高度超画面 55%，整体按比例缩字号（下限 14px）**，保证超长备注完整入画不被裁切。

### 必填 key 按需化（v0.23）

- **恒必填**：`可编辑列`、`功能`
- **按需必填**：`相片备注` / `相片文件名` / `目录` —— 仅当「功能」含 `拍照` 或 `视频` 时必填。
  一个纯填表、不拍照的 Excel 不必为了过校验硬写三条拍照模板。

### 结果联动规则（frontend，通用）

结果列按既有命名约定 `<列>选项` 自动定位（如 `检查结论选项` → `检查结论` 列）；
联动字段取 `日志字段`，**按列名判角色**：名含 `人`/`员` → 填当前登录用户；含 `日期`（无则含 `时间`）→ 填今天。选空则除结果列外全部清空。

→ 换一套列名（如 `检查人/检查日期/检查结论/检查备注`）只需在参数 sheet 写 `检查结论选项` + `日志字段`，**不用改代码**。

约定要点（详见 doc/010）：

- key 名**只认 `unique-key` 这个英文写法**（C02：未知 key 报错），中英文混写会被解析器拒绝。
- 类型/默认值/说明/示例四列是**给人看的文档列，解析器不消费**——填了「默认值」不会生效，真正生效的是 value。新模板请把 `unique-key` 行的这些列补上，方便他人理解。
- 数据 sheet 约定名 **`data`**（参数 sheet 固定名「参数」）。命名为 `data` 时可容忍工作簿里另有说明页/汇总页；没有 `data` 且存在多个非「参数」sheet 时会上传失败并列出全部 sheet 名。
- 唯一键列**不做代码级只读**，如需保护请在「可编辑列」里排除它（解析器会拦"唯一键出现在可编辑列"的矛盾配置）。
