# 006 - v0.8 迭代记录_拍照本地化与验收联动增强

## 1. 需求背景（用户原话）

> 图片不在上传服务器，只是大概提示已经拍摄图片名，不在提供预览图片，前后端导出excel；导出按上传模板导出；验收结果选择参数里面的选项，验收人和验收时间更新，目前前端没有看到验收人字段更新，但是如果从已经有验收时间的选择空，就是没有验收，验收人和验收数据清空，验收备注也清空，是否需要做变更日志，记录验收人，验收时间，验收结果，验收备注？图片是否可以压缩，图片后缀时间前是否加上拍照人名。

确认结论：变更日志「需要，只记验收4字段」；浏览器端拍照「下载到本地」；压缩「最长边1600px/质量85%」；拍照人名「加 {{拍照人}} 占位符」。

## 3. 设计方案

- C07 新约束：相片不落服务器。App 端存系统相册（原通道保留，失败回退浏览器下载）；浏览器端水印+压缩后触发下载；前端仅以 localStorage 记录「已拍摄文件名」提示（按工作簿+小班号，≤500 条），不提供图片预览。
- 导出：上传时原样留存 `data/workbooks/<wid>/source.xlsx(.xlsm)`，导出时用 openpyxl 打开原模板 → `delete_rows(2, max_row-1)` 清示例数据 → 回填数据行，格式/参数 sheet 全保留。前端新增 `/api/workbooks/<id>/export`（登录即可），后台 `/admin/api/workbooks/<id>/download` 复用同一 `_export_workbook()`。
- 验收联动 `syncAcceptCols()`：选非空 → 验收人=登录用户、验收日期(时间)=今天；选空 → 三字段（验收人/验收日期(时间)/验收备注）全清。列存在才动（通用不硬编码模板）。setValueFromCoords 后增加单元格 DOM 强刷双保险。
- 变更日志：SQLite `accept_logs` 表（workbook_id/row_idx/xiaoban/field/old/new/operator/created_at），`api_save_row` 内对验收4字段（验收人/验收日期/验收时间/验收结果/验收备注，列存在才记）做 diff 落库；后台新增「验收变更日志」表（最近300条）。
- 压缩：`drawWatermark` 绘制时按 `min(1, 1600/max(w,h))` 缩放，JPEG 质量 0.85。
- `{{拍照人}}`：param_parser RESERVED_PH 增补，前端 renderTpl 解析为当前登录用户（C01 参数驱动，模板自配置）。
- 缓存熔断：index.html/admin.html 引用 app.js/admin.js 加 `?v=0.8`，发版改版本号。
