# 004-后台与账号需求（v0.3）

> 版本：v0.3 ｜ 日期：2026-09-11 ｜ 来源：用户补充指令（17:00）｜ 关联：doc/003、C03/C05

## 一、需求

1. **模板驱动一切变化**：上传什么模板，前端网格（列/可编辑/隐藏/选项/搜索）与水印备注文字就按该模板的「参数」sheet 变化
2. **水印日期不变**：水印中的日期是固定行为（拍摄当天，格式固定），不进参数表、不随模板变化——模板只控制备注文字
3. **后台能力**：管理后台需支持 上传模板 + 下载 Excel 表格 + 下载轨迹
4. **部署互不影响**：本地预览阶段零部署；将来部署独立端口/路径/appId，不碰 hqz-survey / hqz-cam-app（C03）
5. **账号**：管理员 **雷华雄 / lhx123**，可访问当前应用前端与后台（C05）

## 二、验证

- 数据 sheet 实际表头（A–M 共 13 列）：项目名称/标段/乡镇/村/小班号/小班面积/抚育方式/株数强度/蓄积强度/验收人/验收日期/验收结果/验收备注 —— 参数 8 键引用全部命中
- 发现并修正：`相片文件名` 原 `{{分类}}` 非真实表头（C02 会报错）→ 已改 `{{标段}}_{{乡镇}}_{{村}}_{{小班号}}_{{时间}}` 并同步 xlsx 与 data/ 副本
- 「株数强度/蓄积强度」存在文本 `20%` 与数值 0.18 双存储——上传解析时统一规范化为文本百分比

## 三、设计

### 3.1 架构（修订 doc/003：轻后端，不再是纯前端）

```
浏览器前端                        Flask 本地服务（127.0.0.1:8720，独立端口）
┌────────────────┐    HTTP    ┌──────────────────────────────┐
│ 登录（雷华雄）  │──────────>│ /login /api/* （用户端）      │
│ 工作簿列表      │           │   上传解析(openpyxl+参数校验)  │
│ jspreadsheet网格│<──────────│   行数据读取/保存(JSON)       │
│ （参数驱动渲染） │           │ /admin/*（后台，admin 角色）   │
│ 拍照/轨迹(B2/B3)│──────────>│   模板管理/下载Excel/下载轨迹  │
└────────────────┘           │ SQLite(users+workbooks)      │
                             └──────────────────────────────┘
```

- 解析仍在前端可视渲染，但 xlsx 解析、C02 参数校验放**服务端 openpyxl**（与 hqz-survey 同源做法，稳）；SheetJS 方案撤销（doc/003 §3.2 反转）
- **水印日期**：前端拍照时固定拼 `YYYY-MM-DD`，硬编码日期格式（不参数化），备注文字走 `相片备注` 模板
- 轨迹文件（GPX）由前端 B3 生成后 POST 到 `/api/track`，后台统一下载 zip
