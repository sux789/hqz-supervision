管理层修改说明给管理人员看 · 不需要懂程序

适用文件：data/验收流程设计/造林项目-验收模板-含验收流程.xlsx　|　配套：《验收流程设计说明.md》《验收流程设计-附件按钮解说.html》

1先搞清楚：这份 Excel 里每个页签是什么、能不能动

页签（sheet）能不能改它是什么
data不能改 小班本底数据（600 个小班）。这是全系统验收的对照基准，任何人都不改；现场人员只能填最后 4 列（验收人/验收日期/验收结果/验收备注）。
参数管理层可改 全局配置：照片水印、文件名、下拉选项、哪些列可编辑、照片压缩等。按第 3 节的说明改，只改 value（B 列），不动 key（A 列）。
验收流程管理层可改 流程登记表：决定「哪个流程、对哪些小班、对哪些文件生效」。加一行 = 启用一个流程，是管理层最常用的页签。
流程-XXX管理层可改 流程定义表（页签名必须以 流程- 开头）：一个流程里有哪几个验收环节、查什么、要不要拍照/上传。按第 4 节的说明改。
使用说明— 简版说明，打开文件第一眼就能看到；本页是详细版。
总原则：改 Excel 就是改系统。加流程、改环节、调下拉选项，都在 Excel 里完成，手机端自动跟着变，不需要找技术人员改程序。

2最常用的三件事，照着做

① 新增一个验收流程（例如"经济林补植流程"）

  1. 复制一个现成的流程页签（右键页签 → 移动或复制 → 建立副本），把副本改名为 流程-经济林补植（必须以 流程- 开头，名字不能和已有的重复）；
  2. 在副本里逐行修改验收环节：改环节名、核验因子、附件要求等（各列含义见第 4 节）；
  3. 回到 验收流程 登记表加一行：流程sheet名填 流程-经济林补植、启用填 是、条件字段/条件值按第 4 节语法填、优先级填一个没用过的数字；
  4. 保存，完成。手机端重新打开即生效。

② 临时停用 / 恢复一个流程

  1. 打开 验收流程 登记表，找到那一行；
  2. 把「启用」列改成 否 即停用；改回 是 即恢复；不要删行——删了历史配置就找不回来了。

③ 只让某个文件用某个流程

  1. 在 验收流程 登记表那一行的「适用范围」列：填 全部 = 所有文件都用；填具体文件名（如 造林项目-验收模板.xlsx）= 只有这个文件用。

3参数页说明：每个 key 是什么、怎么改、改错会怎样

参数页只有 6 列：key | value | 类型 | 默认值 | 说明 | 示例。只改 value（B 列），A 列的 key 名一个字都不要动；E 列说明、F 列示例可以随手参考。

key管什么怎么改（管理层操作）改错的后果
相片备注照片上烙的水印文字增删文字和 {{列名}} 占位符，如改成 {{标段}}-{{小班号}} {{验收人}}占位符拼错（如 {{小班号}} 少打括号）→ 水印显示原文不替换
相片文件名照片保存的文件名可用的占位符：{{标段}} {{小班号}} {{时间}} 等；{{时间}} 会变成 20260911_153000 这样的时间文件名重名 → 照片可能互相覆盖，建议保留 {{时间}}
目录照片在云端的存放文件夹用 / 分层，如 {{sheet名称}}/{{小班号}}开头多写一个 / 会出现 // 双斜杠目录（程序已做兼容，但仍建议别多打）
验收结果选项「验收结果」列的下拉选项多个选项用半角分号隔开，如 合格;不合格;整改后合格用了中文分号 ； → 会被当成一个选项
可编辑列现场人员允许填写哪些列列名清单用半角分号隔开，必须与 data 页表头一字不差（含空格）列名写错 → 现场人员改不了那一列
不显示列手机端隐藏哪些列列名清单用半角分号隔开；留空 = 全部显示列名写错 → 该列照常显示（不会报错）
功能App 功能开关可选值：拍照、视频、轨迹、打卡，半角分号分隔拼错字 → 该功能不开
搜索选项列表页的搜索/筛选控件格式 字段名\|select（下拉）或 字段名\|search（输入搜索）字段名与 data 表头不一致 → 该筛选不出现
压缩最长边照片压缩后的最长边（像素）填数字，常用 1440 或 1920填太大 → 上传慢；填太小 → 照片模糊
压缩质量照片压缩质量0.1 ~ 1 之间的小数，常用 0.8填错格式 → 压缩异常
unique-key小班的唯一编号列不要改 固定为 小班号改了 → 照片/数据对不上小班
导出筛选导出资料时的筛选控件格式同搜索选项：字段名\|select 或 字段名\|date字段名写错 → 该筛选不出现
通用注意：① 分隔符一律用半角分号 ;，不是中文分号；② {{列名}} 里的列名必须与 data 页表头完全一致——特别注意 data 表头「总株数」末尾带着 2 个空格，引用它时原样保留；③ 改参数前先复制一份 Excel 备份，改完让技术员或现场人员试一下再正式用。

4流程 sheet 说明：11 列各填什么

列管理层怎么填
序号1、2、3…连续编号，代表验收先后顺序。加环节后续着编，别跳号。
验收环节工序名称，如 整地、回塘及底肥放置、栽植、撑杆覆膜、成活率核验。
验收类型固定几种：前置确认（开工前的边界确认）/ 转序验收（各工序）/ 完工验收（成活率）/ 竣工验收（保存率）/ 年度验收 / 抚育验收。
核验因子这个环节必须查的内容清单。凡写了的、且「填报要求=必填」的，现场人员不填完提交按钮就是灰色，这是防漏填防造假的核心开关。
标准值来源两种写法：① 写 data 页的列名（如 整地规格）→ 手机端自动把本底标准值带出来对照；② 写 项目作业设计 → 无对应列，现场按方案人工判断。
填报要求必填 或 选填。也可带条件，如「该列有值的小班必填」。
校验方式怎么算合格：实测对照标准值 / 现场核验 / 抽查实测 等，写给现场人员看的口径。
附件要求控制手机端出什么按钮（详见配套《附件按钮解说》）：
· 拍照:整地现场照片 → 只出拍照按钮（App 内实时拍摄、禁相册、自动上传）
· 上传:三证一签 → 只出上传文件按钮（可选照片或 PDF，适合证件）
· 拍照:回塘照片;上传:底肥单据 → 两种都出（半角分号隔开）
· 拍照:现场照片@2 → 至少拍 2 张才能提交
· 留空 → 该环节没有按钮
通过标准合格线，如「实测规格 ≥ 设计规格」「成活率达到设计要求」。
转序规则这个环节什么时候才能做：如「上一环节合格方可填报」「全部转序验收合格后方可进行」。
备注写给现场人员的补充口径（分批填报、证件份数、确认人取登录账号等），随便写，不影响程序。

「验收流程」登记表的条件怎么填（决定流程对谁生效）

想要的效果填法
所有小班都执行条件字段填 1（或留空），条件值留空
只对"退化林修复"的小班执行条件字段填 项目类型，条件值填 退化林修复
"退化林修复"或"四旁植树"都执行条件值填 退化林修复;四旁植树（半角分号 = 满足其一）
既要退化林修复、又要 2026 年的条件字段 项目类型;实施年度，条件值 退化林修复;2026年（一一对应，全部满足）
一个小班命中两条流程怎么办按「优先级」列数字小的执行，优先级别填重复的数字

5红线清单：改之前先看这一条

  • ✗ 不改 data 页的任何数据、任何表头（表头是程序认列的依据）。
  • ✗ 不改 参数 页 A 列的 key 名，不删 key 行。
  • ✗ 不改流程页签的 流程- 前缀（改了 App 就不认它是流程表）。
  • ✗ 不合并单元格、不删第 1 行表头、不在表头行上方插行。
  • ✗ 不用中文分号 ； 做分隔符，一律半角 ; 。
  • ✓ 停用流程用「启用=否」，不删行。
  • ✓ 改之前复制一份 Excel 备份；改完先让一个现场人员试，再全面铺开。

改完自查 30 秒（对不上就先别发）

检查项合格标准
新流程页签名以 流程- 开头，与已有页签不重名
登记表里加的那一行「启用」只有 是/否 两种值；「优先级」没和别的行重复
条件字段/条件值字段名与 data 表头一字不差；条件值与 data 里实际填的值一致（如「补植修复+采伐修复」是一个整体值）
「可编辑列」改过的每个列名都能在 data 表头里原样找到
附件要求列冒号、分号、@ 都是半角；不需要按钮的环节留空
拿不准就问。Excel 改坏了不影响手机上已上传的照片和已提交的数据（那些在服务器上）；真正危险的是把 data 本底数据改了——所以这一条永远不要碰。
