## 修改密码 + 长期登录（08:46）
- 用户确认需求：本人改自己、管理员改他人、登录长期保存、**不影响别人（多人登录互不影响）**。
- 实现：①`POST /api/password`（本人，验原密码，返回**新令牌**本机免重登）②`GET /admin/api/users` + `POST /admin/api/users/<name>/password`（管理员重置他人，无需原密码）③`_TOKEN_DAYS` 180 → **3650（10 年）**④令牌增加**密码版本**：`users.pwd_ver`（迁移加列），改密码时 +1 → 该用户旧令牌失效；**旧格式令牌兼容**（rsplit 后长度 3 → 不校验版本），避免上线即全员登出。
- 前端：App 点右上角姓名 → 修改密码弹层（原/新/确认 + 三条校验：≥4 位、两次一致、不得与原密码相同）；后台「用户管理」卡片（列表 + 每行输入新密码 + 重置，带 confirm 提示）。
- **测试（本地 + 线上双跑）**：错误原密码 403；改密成功返回新令牌；旧令牌 401、新令牌 200；**他人令牌仍 200（关键）**；旧密码登录 401、新密码 200；普通用户访问 /admin/api/users 403；管理员重置他人 → 被改者 401、**其他人与管理員自己 200**；6 个账号密码最终复核全部 200（测试改动已恢复原值）。

- 「不影响别人」的技术口径：令牌按用户维度签名且带各自密码版本，**改密只失效该用户的令牌**；多人可同时在线（各自设备各自令牌）。
