## v0.52 材料核验（项目级按批次 + 多小班覆盖）

- 需求：苗木核验/肥料核验 这类环节要能勾多个小班 + 传图片/PDF，提交后对应小班不再提示；
  用户四轮拍板：**按环节各自判定**、**不通过不算覆盖**、**参数页一个 key**、**提示只放小班面板顶部**。
- 关键技术事实（下次别再摸一遍）：
  - 老格式（flow_config/1）早就支持 `关联小班=多选` + `row_idx=-1`；**v2 一行都没有** ——
    `_tpl_hit` 入口就 `ridx<0 → None`，`STEP_COLS` 没有「关联小班」列。
  - `parse_routes` 对「流程路由」做**表头全等校验**（`headers[:len(COLS)] != ROUTE_COLS`），
    所以「项目级」开关**不能加列**，只能走参数页 key（`材料核验流程`）。
  - 环节 sheet 的 `_read_sheet` 不校验表头，**尾列可以随便加**（短表自动补空）→ 关联小班加在尾部最安全。
  - 覆盖判定：`flow_records` 里 `row_idx=-1` 按 `rec_no` 归并；某环节覆盖该小班 =
    该环节「关联小班」含此号 **且** 该次 `result ∈ PASS_RESULTS`。
  - 附件按 rec_no 绑定，**同一 id 不能跨记录复用**（写测试时第二批必须重传，否则 400）。
- 顺手改的 UX：多选 >20 项出筛选框；项目级面板隐藏顶部小班选择栏（否则会误读成"只报当前班"）。
- 验证：回归 467 全绿、七门 PASS；Chrome 430px（headless + 自写 CDP，`/tmp/cdp.py`）
  截图确认绿/橙两态、298 勾选框、筛选、恢复。
