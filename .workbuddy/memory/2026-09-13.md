## v0.10.1 视频改为手机端录制压缩（13:00 后）
- 用户反馈：视频不会上传；要求在手机上压缩、参数后台设置；并报告百度云出现大量空目录（"源目录后加时间"）。
- 空目录问题=v0.10 已修复的百度 mkdir 同名转存（12:50 修 mkdir_p 改先查再建 + 清理历史空副本），已向用户确认并出示证据。
- 架构调整（C09 修订）：WebView 无法转码已有视频文件 → 改为 **MediaRecorder 边录边压**为主路径：
  · 「🎬 视频」→ 菜单：①录制（推荐）②选择已有视频（服务器 ffmpeg 压缩兜底）
  · 录制参数从后台 settings 下发（/api/video/params）：720p/2500kbps/30fps/最长60s/上限300MB
  · 上传带 precompressed=1 → 服务器跳过 ffmpeg 直接推七牛+百度；输出容器按 MediaRecorder.mimeType 定 ext（mp4/webm）
  · 无声录制：AndroidManifest 有 CAMERA 但无 RECORD_AUDIO → 有声需重打包 APK（后续项）
- 测试：playwright + 假摄像头（--use-fake-device-for-media-stream，executablePath 指向 ms-playwright/chromium-1208）实测录制 5s → 166KB → /api/video 200 → 百度 YJ-515 目录落盘 baidu_ok（服务器未二次压缩，precompressed 生效）。测试文件已清理。
- 坑：录制遮罩 `.rec-mask video{flex:1}` 无 min-height:0 → 视频不收缩把底部按钮挤出视口（playwright 报 element is outside of the viewport）→ 改 flex:1 1 auto + min-height:0 + 工具条 flex:0 0 auto。
- 部署 v=0.10.1，线上 /api/video/params 返回正常。
