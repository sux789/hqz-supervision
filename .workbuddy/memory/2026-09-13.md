## 2026-09-13 v0.9.1 修复拍照 quality 报错
- 用户报：拍照报 "quality is not defined"。根因：v0.9 前端压缩参数化的 3 处编辑中，toBlob 行落盘了，但 drawWatermark 签名(opts)与调用点传参两处被 Edit 工具"报成功未落盘"（零宽字符路径 flaky 现象再次出现）→ 运行时 quality 未定义，拍照直接失败。
- 修复：改用 python 脚本补齐两处（assert in + replace，先 find 验证），grep + node --check 双验证；缓存 v=0.8.4；deploy 上线 curl 验证（页面 v=0.8.4、live app.js 含 opts.quality）。
- 教训固化：此项目路径含零宽字符，所有代码编辑必须"编辑后 grep 复核"；重要改动优先用 python 脚本 assert+replace 而非 Edit 工具。
