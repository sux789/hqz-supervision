
## v0.32.6（15:52 部署，commit fbbc623）：切小班验收面板不刷新 + 轨迹授权三分支

## v0.32.7（16:10 部署，commit 9c92c3b）：修「点轨迹无任何提示」
- v0.32.6 改完按钮后用户报"点轨迹没有提示"。jslog 无新错（jspreadsheet touchEndControls 的 TypeError 是 vendor 噪音）→ 判定 handler 挂死：**老 APK 桥上 status()/drain() 返回永不落定的 Promise**，await 卡死，try/catch 抓不住"不返回"。
- 修：nativeTimeout(p, ms) 竞速包装——status/drain 2s、权限 request 10s，超时按 null 走"版本较旧请升级 v0.10+"分支；attachTrack 启动路径同样不可挂死。app.js?v=→0.32.7，237 全绿，已部署。
- **新教训（并入 C 系列）：await 原生桥调用必须限时**——"Promise 永不落定"是 try/catch 的盲区，凡跨 JS↔原生边界的调用都要 nativeTimeout；症状特征 = "点了没任何反应且 jslog 无错"。
